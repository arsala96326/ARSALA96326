# ARSALA96326 — International Cuisine

Premium, responsive restaurant brand website built with HTML, CSS and vanilla JavaScript.

## Pages
Home, Menu, Our Story, Gallery, Contact, FAQ, Privacy, Terms.

## Features
Responsive navigation, searchable and category-filterable sample menu, editorial gallery, accessible semantic structure, demo inquiry form.

## Preview
Open `index.html` in a browser. Internet is needed to load Unsplash photos and Google Fonts.

## Deploy to GitHub Pages
Create a public repository (for example `arsala96326-restaurant`), upload the **contents** of this folder to its root, then enable Settings → Pages → Deploy from a branch → main → / (root).

## Important
This is a **concept/demo**. No restaurant, booking service, online ordering, payments, verified location, opening hours or live inquiry processing are represented. Sample menu prices are in USD. Replace demo policies, photos, and contact mechanism before real commercial launch.

Brand colors: #151515 / #D4AF37 / #FFF8EB. Language: English.
